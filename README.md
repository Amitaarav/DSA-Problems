# Data Structures & Algorithms Practice

This repository contains my solutions to problems from **Codeforces** and **LeetCode**.  
The goal is to consistently improve problem-solving skills, strengthen DSA fundamentals, and prepare for coding interviews and competitive programming.

---

##  Platforms

- 🟢 Codeforces
- 🔵 LeetCode

---

## Objectives

- Build strong fundamentals in Data Structures & Algorithms  
- Improve coding speed and accuracy  
- Practice different problem-solving patterns  
- Prepare for technical interviews  
- Perform well in contests
